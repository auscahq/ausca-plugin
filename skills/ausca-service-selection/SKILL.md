# Ausca service selection

Use this skill when a user needs document OCR or analysis, transcription, a browser session, or a receive-only agent inbox through Ausca.

1. Search the current offers and resolve the exact active or pinned offer revision. Read the offer's input limits, lifecycle, retention and cost conditions from the returned contract and [MCP guide](https://ausca.com/docs/mcp).
2. Prepare the intended invocation with real input to obtain binding terms. Treat preparation as a quote or admission step, not as completed work or payment.
3. Before a payable call, present the current terms and confirm that the host has an x402-capable payment path and the user has authorized that exact spend. Do not infer payment authority from plugin installation or a discovery tool.
4. After invocation, read authoritative status, result and receipt. If the operation is pending, failed, expired or cancelled, report that state. A signed download-access URL or browser connection is scoped and time-limited; do not describe it as a permanent public artifact.

The MCP exposes a service lifecycle, not an unlimited local browser or inbox. Use the [service skills](https://ausca.com/skills/) for the current limits of each offer.
